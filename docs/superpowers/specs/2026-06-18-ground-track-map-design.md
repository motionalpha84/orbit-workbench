# 星下点轨迹地图设计

## 背景

在现有航天器轨道模拟网站中，新增星下点轨迹仿真功能。该功能基于当前 3D 轨道传播、地球自转、ECI/ECEF 坐标系和二体/J2/J3 动力学模型，不另建独立轨道系统。目标是在保持现有 3D 地球主视图风格的基础上，增加一个可展开的 2D 世界地图分析面板，用于观察、筛选、导出和统计卫星星下点轨迹。

## 界面范围

新增底部可展开的“星下点地图”面板，默认收起，不遮挡现有 3D 地球主视图。底部控制区增加入口按钮，点击后地图面板从底部展开。

地图面板包含三种状态：

- 收起：只保留入口按钮。
- 窗口模式：从底部展开，占用下方一部分屏幕，3D 场景仍可见。
- 全屏模式：地图铺满主视图区，效果接近独立 2D 地图视图。

地图右上角提供视图按钮：

- 窗口
- 全屏
- 关闭

地图底图使用项目内置的高清离线深色世界地图，不依赖网络服务。地图采用等经纬度矩形投影，经度范围 `-180° ~ 180°`，纬度范围 `-90° ~ 90°`。底图上叠加经纬网、轨道颜色图例和星下点轨迹。

## 星下点计算逻辑

星下点轨迹基于当前网站已有轨道传播结果计算，不单独创建另一套轨道模型。

计算流程：

1. 对每条需要显示的轨道，按地图时间窗口生成采样时刻。
2. 使用当前选择的动力学模型传播轨道：二体运动、`J2` 摄动或 `J3` 摄动。
3. 得到每个采样时刻的 `ECI` 位置向量。
4. 根据全局“仿真起始 UTC 时间”和对应仿真秒数计算地球自转角或格林尼治恒星时。
5. 将 `ECI` 位置转换到 `ECEF`。
6. 将 `ECEF` 位置转换为地理经纬度。
7. 将经纬度投影到 2D 地图坐标。

新增全局参数：

- 仿真起始 UTC 时间
- 默认值为当前 UTC 时间
- 放在主工作台中，作为全局仿真参数
- 影响星下点经度，也为后续地面站或覆盖分析保留统一时间基准

约定：

- 纬度范围限制在 `-90° ~ 90°`。
- 经度归一化到 `-180° ~ 180°`。
- 当轨迹跨越 `±180°` 经线时自动断线，避免地图上出现横穿全球的错误连线。
- 星下点模型始终跟随当前动力学模型，保证 3D 轨道与 2D 地图语义一致。

## 地图轨迹与筛选

地图默认显示所有“当前可见轨道”的星下点轨迹，每条轨迹沿用 3D 轨道颜色。

地图面板内新增筛选器：

- 显示所有可见轨道名称和颜色。
- 每条轨道可单独开关星下点显示。
- 默认全部开启。
- 如果某条轨道在主工作台中被隐藏，它也不会出现在星下点地图筛选器中。
- 如果主工作台重新显示该轨道，它会重新进入地图筛选器，默认开启。

轨迹表现：

- 历史轨迹：较淡实线。
- 未来轨迹：同色虚线。
- 当前星下点：高亮圆点。
- 当前选中轨道：轨迹和当前点略微增强。
- 非选中轨道：保持可见，不强制变暗，避免多轨道对比时信息丢失。
- 仿真运行时，2D 星下点地图显示与轨道颜色一致的粒子动效，用于强调当前运动方向和轨迹流动感。粒子效果只用于视觉辅助，不改变轨迹数据。

悬停行为：

- 鼠标悬停在轨迹或当前点上时显示浮动提示。
- 提示内容包括轨道名称、经纬度、仿真时刻、对应 UTC 时间和动力学模型。

## 时间窗口与播放联动

星下点地图使用可设置的时间窗口，支持两种模式：

- 按圈数：例如过去 `1` 圈、未来 `1` 圈，圈数基于对应轨道周期计算。
- 按时间：例如过去 `60 min`、未来 `60 min`。

默认值：

- 时间窗口模式：按圈数
- 过去：`1` 圈
- 未来：`1` 圈

与仿真播放联动：

- 地图上的当前星下点跟随底部模拟仿真时刻移动。
- 点击“运行”时，当前点和粒子流动效果同步更新。
- 点击“暂停”时，当前点停在当前仿真时刻，粒子动效暂停或进入极慢呼吸状态。
- 点击“重置”时，当前点回到 `t = 0` 对应位置。
- 切换速度倍率时，地图当前点按相同倍率运动。
- 切换二体、`J2` 或 `J3` 后，地图轨迹重新计算。
- 修改轨道六要素或导入轨道后，地图轨迹同步刷新。

性能约定：

- 每条轨迹按当前窗口动态采样。
- 采样密度随窗口长度和轨道周期自适应，保证大范围轨迹平滑，但避免过多点导致卡顿。
- 地图收起时暂停高频绘制，只保留必要状态更新。
- 地图展开或全屏时恢复绘制。

## 性能档位

工作台底部新增性能设置区域，包含：

- 节能
- 均衡
- 高性能
- 自定义

默认使用“均衡”。

各档位含义：

- 节能：降低 3D 轨道参考点密度、星下点轨迹采样密度和粒子数量，适合普通集显或多轨道数量较多时使用。
- 均衡：保持当前网站流畅体验，轨道和星下点轨迹清晰但不过度采样，作为默认档位。
- 高性能：按 `8GB+` 显存目标设计，提高 3D 完整轨道参考采样密度、星下点历史/未来轨迹采样密度、粒子数量和轨迹平滑度；地图全屏时优先保证视觉精度。
- 自定义：用户可输入网页允许使用的最高显存预算，例如 `2GB / 4GB / 8GB / 12GB`。系统根据该预算限制单条轨道最大采样点数、星下点轨迹最大采样点数、粒子数量、地图缓存数据量和高密度动画效果。

重要约定：

浏览器网页不能像原生软件一样精确读取或强制锁死真实 GPU 显存占用，因此“最高显存”作为应用内部资源预算，用于限制几何点数、粒子数、缓存数组和贴图/画布规模，避免资源无限增长。

高性能模式按 `8GB+` 显存目标配置，但保留基本保护：如果轨道数量特别多或时间窗口特别大，会自动降采样，优先保证页面不崩溃。

## 地图交互、框选统计与导出

地图交互：

- 支持鼠标滚轮缩放。
- 支持鼠标拖拽平移。
- 支持框选区域查看。
- 支持重置地图视图。
- 地图视图状态在当前会话中保留。

框选行为：

- 用户框选地图区域后，地图自动缩放到该区域。
- 同时统计该区域内经过的星下点轨迹。
- 地图上显示一个浮动摘要弹窗。
- 地图面板右侧显示完整统计栏。

浮动摘要显示：

- 区域经纬度范围
- 命中的轨道数量
- 命中的轨迹点数量
- 最早 / 最晚经过时间

右侧统计栏显示：

- 轨道名称
- 轨道颜色
- 经过时间段
- 经纬度范围
- 命中点数量
- 当前动力学模型

导出功能：

- 导出 CSV：导出当前地图筛选轨道、当前时间窗口、当前动力学模型下的星下点数据。字段包括轨道名称、轨道 ID、仿真秒、UTC 时间、经度、纬度和动力学模型。
- 导出截图：如果地图面板关闭，导出现有 3D 场景截图；如果地图面板处于窗口模式，截图包含 3D 场景和当前地图面板；如果地图处于全屏模式，截图导出当前全屏地图视图。

## 实现边界

- 不引入在线地图服务。
- 不依赖网络瓦片。
- 世界地图底图作为本地资源加入项目。
- 地图投影固定为等经纬度矩形投影。
- 星下点轨迹只表达卫星在地球表面的投影点，不做覆盖范围、传感器视场、地面站可见性。
- `J2` / `J3` 星下点轨迹跟随当前已有动力学模型。
- 多轨道大窗口场景下允许自动降采样，以保证页面稳定。

## 测试计划

- `ECI -> ECEF -> 经纬度` 转换测试。
- UTC 起始时间与地球自转角测试。
- 跨越 `±180°` 经线时轨迹断线测试。
- 时间窗口按圈数 / 按时间生成采样点测试。
- 星下点筛选器只显示可见轨道测试。
- CSV 字段和内容测试。
- 性能档位采样预算测试。
- 静态文件测试：确保地图面板、筛选器、导出按钮、性能选择 UI 存在。
- 浏览器验证：展开地图、切换全屏、运行仿真、缩放平移、框选统计、CSV 导出、截图导出。
