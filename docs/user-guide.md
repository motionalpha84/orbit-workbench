# 工作台操作手册

## 建立轨道和设置 UTC

在右侧「轨道档案」填写轨道名及六根数：半长轴/km、偏心率、轨道倾角/deg、升交点赤经/deg、近地点幅角/deg、真近点角/deg，点击“生成轨迹”。选中轨道时档案显示其名称与六根数；未选中时输入框显示「-」，点击即可直接输入。点击轨道卡片上的铅笔进入编辑（卡片标记 `/// REVISED`，轨道名称右上角显示「编辑中」），再次点击铅笔或「编辑中」上的 × 取消编辑；「清空」只清空输入框。角度仍以度为单位。支持椭圆轨道，要求 `0 <= e < 1`，且近地点高于地球表面。空场景也可点击“载入演示轨道”快速开始。

“仿真起始 UTC”输入按 **UTC** 解释，即使浏览器所在时区是北京时间也不转换成当地时间。UTC 用于星下点的地球转角与时间标记。轨道颜色在档案中点击「轨道颜色」后向左弹出，可用色盘、RGB、HEX 或色板设置；在轨道名册中可选择、多选（点击即切换）、编辑、显隐和删除轨道，卡片显示轨道分类（LEO / MEO / GEO / IGSO / Molniya / HEO）。

场景右下的 FRAME 菜单切换 **ECI / ECEF**，MODEL 菜单选择中心天体并切换 **二体 / J2 / J3** 模型，ORB 菜单列出当前显示的轨道。J2/J3 保留 v1 的近似模型，不是新增高精度数值积分器。

## 导入现有轨道

“资产”抽屉提供 JSON 和 TXT 导入。支持 v1 的 `version:1 + snapshot + units` JSON，以及直接包含 `orbits` 的旧 JSON。TXT 格式为名称行后每行一个根数值，完整六值和五值版本均支持，五值版本的真近点角默认 0。

导入成功后替换当前场景，暂停并将仿真时间归零，清理此前的地图历史和标定结果。可从 v1 导出 JSON，再在 v2 资产模块导入；两个默认端口的浏览器存储相互独立，不会自动共享存档。

## 运行、定位与观察

底栏提供运行、暂停、时间重置，以及 **1 / 60 / 600 / 3600 / 6000 / 86400** 倍速。运行按钮旁的下拉菜单可限制现实运行时长，0 表示不限时。双击仿真时刻可切换 s/min/hr/day。

拖动时间轴可定位仿真时刻；定位会暂停播放，并重新开始地图历史、清除旧标定结果，避免把不同时间段的分析混在一起。三维场景支持拖动旋转、平移、滚轮缩放，正视图、俯视图和视角重置。地球经纬网常驻显示；坐标轴、黄道面、赤道面、完整参考轨道在「视图 / 图层」面板中独立开关。

场景左上 HUD 显示选中轨道的周期、近地点/远地点高度、速度范围，右上显示后台返回的当前 ECI 位置和速度。大量轨道时，轨道列表、状态菜单和地图筛选使用**每页 80 条**的搜索分页，分页只限制显示条目，不删减数据集。

场景左上 HUD 跟随当前查看的轨道；多选时显示最近选中的一条，并以 `+N MULTI` 注明其余选择数。近/远地点高度来自后台准备的轨道参数指标，不是每帧重新拟合的瞬时根数。名册卡片 `/// SELECTED` 表示已选中，`/// REVISED` 表示正在编辑。仿真时刻显示为 `T+ 00000.0 s`，超过五位时完整显示，双击仍可切换单位。

## 星下点地图

从左侧图标栏进入“星下点”视图，在地图工具栏 TRACKS 中勾选需要记录的轨道；新增轨道默认不勾选，三维隐藏轨道不参与地图。历史从开启记录的当前仿真时刻开始，支持按圈数或时间保留；0 个历史圈仍显示当前圈。已经裁剪的历史不会因扩大保留窗口自动补回。

地图支持缩放、拖动、经纬辅助线、轨迹点悬停、Shift+拖动或右键拖动框选统计。可窗口/全屏切换、最小化、关闭和重置视角；框选后「区域统计」模块列出各轨道命中点数、最早/最晚 UTC 与经纬范围，可清除选区或导出统计 CSV。**最小化或切换到其他视图时继续记录，关闭停止并清除历史。** 资产模块可导出 1920×1080 地图 PNG 和 CSV。

## 矢量标定

左侧图标栏“标定”打开矢量标定抽屉。输入目标名、位置矢量/km 或速度矢量/km/s，以及 ECI x/y/z 分量；添加到列表后可继续添加、修改或删除目标，再点击“标定全部”。

标定由后台执行，按当前模型处理可见轨道。位置与速度目标可以混合；结果按目标显示命中、最近参考及残差，支持展开/折叠和三维标记显隐。清除结果保留目标列表；轨道或模型变化会使旧结果失效。

## 任务与控制台

“任务”视图显示实际连接、线程数、等待任务和当前进度；「任务账本」列出任务类型、状态、进度、耗时和结果大小，并可取消仍在等待或执行的单个任务（可折叠，展开状态随浏览器工作区保存）。

同一视图的“控制台”显示实际计算日志。后台中断时播放暂停，可用“重试连接”恢复；计算不会退回网页主线程。任务与日志用于了解当前运行情况，不是系统命令终端。

## 资产、导出与设置

在“资产”中命名保存当前轨道组，支持加载、更新、重命名、删除和单组 JSON 导出。导出内容保留轨道、颜色、显隐、多选、模型、坐标系、UTC 和地图设置。资产页可导出三维 PNG；地图标题栏的相机按钮可直接导出三维与地图的组合截图，全屏地图时输出地图。

“设置”提供节能、均衡、高性能、自定义采样预算和导出文件名前缀，也可清空场景或退出。性能预设影响显示采样和地图轨道缓存数量，默认高性能地图最多 48 条；自定义预算用于分配显示采样，不是操作系统的内存预留。

资产、标定、设置抽屉支持固定与收起；选中轨道 HUD 可折叠，「视图 / 图层」面板可收进左缘（两者状态随浏览器保存）。窄屏将场景和档案上下排列，导航移至顶部横向图标栏，底栏保持吸底。

## 数据保存与兼容

- **长期资产**：保存在当前浏览器的 localStorage，可导出 JSON 备份或跨浏览器/端口迁移。仍兼容 `eci-orbit-workbench:v1` 与 `eci-orbit-workbench:asset-groups:v1` 键的数据结构。
- **自动恢复**：恢复轨道与工作区设置；批量操作的保存采用短延迟合并，页面离开时刷新待保存内容。存储空间不足时会显示错误，当前场景仍可导出 JSON。
- **运行时数据**：后台数据集、任务结果、地图历史属于内存缓存；服务或线程重启、过期及资源回收可能清除它们。数据集可自动重新注册，地图历史重置会明确提示。
- **原有持久化边界**：标定目标/结果、已经运行的地图历史和播放时间不是长期资产内容。保存轨道组不等于保存这些临时分析状态。
