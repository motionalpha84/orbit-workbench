# 速度矢量圆模块设计

## 背景

在现有轨道模拟工作台中，新增一个“速度圆”模块，用于观察各轨道在速度空间中的速度矢量圆。速度矢量圆定义为：将轨道上一整圈的速度矢量平移到中心天体位置后，箭头端点形成的曲线。该模块应与主 3D 轨道传播、二体/J2/J3 动力学模型、轨道颜色、轨道可见性和仿真时刻保持一致。

该功能不是新的轨道模型。它消费现有 `propagateOrbit(...).velocityKmS` 结果，并在独立 3D 速度空间中可视化。

## 用户界面

右侧模块侧栏在“星下点”和“资产”之间新增“速度圆”入口。点击入口后打开速度圆浮动面板，交互逻辑与星下点模块一致：

- 支持窗口、全屏、最小化、关闭。
- 支持固定 pin。
- 点击侧栏同一入口可打开/关闭。
- 点击面板外部时，未固定模块按现有规则关闭。
- 关闭后停止后台速度圆更新。
- 最小化时保留状态，但不进行高频绘制。

速度圆面板包含：

- 3D 速度空间画布。
- 轨道筛选列表，跟随主场景可见轨道，模块内可单独勾选，默认全开。
- 当前悬停读数浮层。
- 简洁说明状态，例如无可见轨道或当前筛选为空。

资产面板新增“导出速度圆 PNG”按钮，导出当前速度圆模块图像。

## 速度圆计算

新增 `js/velocity-circle.mjs` 作为纯计算模块。输入为轨道记录、当前仿真秒、动力学模型和采样预算，输出用于渲染的数据结构。

每条轨道的数据包含：

- `id`
- `name`
- `color`
- `samples`：以当前仿真时刻为起点，向未来采样接下来一整圈的速度矢量端点。
- `current`：当前仿真时刻速度矢量。
- `trail`：当前速度端点短尾迹，表达近期端点运动方向。
- `speedKmS`：当前速度大小。
- `perturbationModel`

参考速度圆采样规则：

- 以当前仿真时刻为基准。
- 采样当前轨道接下来一整圈。
- 每个采样点调用 `propagateOrbit(orbit, elapsedSeconds, { perturbationModel })`。
- 对二体、J2、J3 使用同一接口，保证与主场景一致。

短尾迹规则：

- 从当前仿真时刻向过去取一小段时间窗口。
- 默认尾迹时长按轨道周期比例计算，并设置上下限，避免低轨过短或高轨过长。
- 尾迹只用于动态视觉，不影响参考速度圆定义。

速度空间坐标采用 ECI 速度分量 `vx/vy/vz`，单位为 `km/s`。该视图不随主场景 ECI/ECEF 开关旋转，因为速度矢量圆在惯性速度空间中更稳定、更符合轨道力学语义。

## 3D 渲染

新增 `js/velocity-circle-view.mjs` 作为独立 Three.js 视图。它不复用星下点 canvas，也不重构主 `OrbitScene`。

渲染内容：

- 深色背景，与现有工作台风格一致。
- 速度空间 `vx/vy/vz` 坐标轴。
- 每条轨道的淡参考速度矢量圆。
- 当前速度矢量箭头，从速度空间原点指向当前速度端点。
- 当前速度端点短尾迹。
- 悬停读数，包含轨道名称、速度大小、`vx/vy/vz`、仿真时刻和动力学模型。

交互：

- 左键拖动旋转速度空间。
- 滚轮缩放。
- 交互手感参考主 3D 轨道场景。
- 悬停参考圆、当前箭头或当前端点时显示读数。

多轨道视觉规则：

- 沿用现有轨道颜色。
- 选中轨道增强。
- 存在选中轨道时，未选中的轨道适度降低透明度，但仍保持可辨识。
- 筛选关闭的轨道不渲染。

## 应用状态与数据流

`js/app.mjs` 新增速度圆状态：

- `velocityCirclePanel`：`closed | window | fullscreen | minimized`
- `velocityCircleFilters`：轨道级勾选状态
- `velocityCircleTracks`：当前渲染数据
- `lastVelocityCircleRenderMs`：渲染节流时间戳
- `velocityCircleExportNamePrefix`：默认 `velocity-circle`

数据流：

1. 主仿真 tick 更新 `elapsedSeconds`。
2. 如果速度圆面板处于窗口或全屏状态，按节流策略重新计算速度圆数据。
3. 将数据、当前选中轨道和播放状态传给 `VelocityCircleView`。
4. 轨道新增、删除、隐藏、导入、动力学模型变化、仿真重置时清理或重建速度圆数据。
5. 资产面板导出速度圆 PNG 时，基于当前状态强制计算一次并导出。

筛选规则：

- 速度圆筛选列表只列出主场景可见轨道。
- 新出现的可见轨道默认开启。
- 主场景隐藏轨道时，从速度圆筛选列表移除。
- 主场景重新显示轨道时，重新进入速度圆筛选列表并默认开启。

## PNG 导出

资产面板新增“导出速度圆 PNG”按钮。

导出行为：

- 文件名前缀默认 `velocity-circle`。
- 固定输出尺寸 `1920x1080`。
- 导出前基于当前仿真时刻、动力学模型、可见轨道和速度圆筛选器强制刷新一次数据。
- 即使速度圆面板未打开，也可导出当前速度圆图像。
- 导出使用当前速度圆视角状态；如果尚无视角状态，则使用默认 3D 视角。

## 性能

速度圆采样纳入现有性能预算思路。高性能模式使用更平滑的参考圆和尾迹采样，节能模式降低点数。

约束：

- 面板关闭时不进行后台更新。
- 面板最小化时保留数据与视角，但跳过高频重绘。
- 多轨道场景限制每条轨道采样点数，避免长期播放时资源增长。
- `VelocityCircleView` 在数据替换时主动释放旧 Three.js geometry/material。

- 生成当前速度矢量。
- 采样接下来一整圈速度圆。

- 验证短尾迹位于当前时刻之前。
- 验证 J2/J3 参数传递。
- 验证异常输入不会产生 NaN 数据。

- 隐藏或零尺寸面板不产生无效 canvas/renderer 尺寸。

- `app.mjs` 存在速度圆状态、事件绑定、tick 更新和导出函数。
- `velocity-circle.mjs` 与 `velocity-circle-view.mjs` 被应用入口导入。

浏览器验证：

- 打开速度圆模块。
- 拖动旋转、滚轮缩放。
- 播放仿真时当前箭头和短尾迹更新。
- 筛选轨道开关生效。

- 窗口、全屏、最小化、关闭状态符合星下点模块。
- 从资产面板导出速度圆 PNG。

## 不在本次范围

- 不做速度圆 CSV 导出。
- 不做速度空间测量工具或框选统计。
- 不将速度空间坐标切换到 ECEF。
- 不把速度圆叠加到主 3D 地球场景中。
