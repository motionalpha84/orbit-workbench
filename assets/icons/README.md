# List action icons

The local outline icons are from [Tabler Icons](https://github.com/tabler/tabler-icons), retrieved on 2026-10-19: `eye`, `eye-off`, `pencil`, `trash`, and `check`.

Their MIT license is retained in `LICENSE-tabler.txt`. The UI uses these SVG files as CSS masks so that selected, hidden, focus, and hover states inherit the appropriate text color. No network request is needed at runtime.
